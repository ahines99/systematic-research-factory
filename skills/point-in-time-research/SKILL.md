# Objective
Perform point in time research with explicit evidence, uncertainty, and approval boundaries.

# Procedure
1. Read relevant MCP resources first.
2. Separate observations, calculations, assumptions, and recommendations.
3. Use tools for deterministic calculations.
4. Cite evidence IDs for material claims.
5. Return NEEDS_EVIDENCE when support is insufficient.
6. Stop for human approval before material actions.
