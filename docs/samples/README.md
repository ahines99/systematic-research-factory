# Recorded sample reports

Generated locally on 2026-09-27 with `rsf --provider rules demo`, a dedicated SQLite database, and a separate file blob store. No production data, API keys or model calls were used. Approval actors are scripted demonstration roles, not real human investment decisions.

The raw HTML and Markdown are application exports. `manifest.json` records the generated deterministic artifact hashes and scenario outcomes. The reports identify their execution runtime; do not interpret this static publication as a hosted backend or as a downloadable replay database. The preserved candidate databases are separately checksummed under `tests/fixtures/replay/`.
