# Security policy

This is an unreleased research portfolio project. No production security support window or response SLA is promised. The maintainer is Alex Hines (`ahines99`).

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/ahines99/systematic-research-factory/security/advisories/new). Do not put credentials or private data in a public issue. For ordinary reproducible bugs, use a GitHub issue with sanitized inputs and the source revision.

See the [threat model](docs/threat_model.md), [candidate risk register](docs/security-risk-register.md), and [operations runbook](docs/runbook.md). Research only: no trading or broker connectivity. Public sample reports contain simulated returns and scripted decisions.
